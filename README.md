# Admin Dashboard

Website admin dashboard dengan data dummy menggunakan React + Vite dan juga style Tailwind CSS.

# Fitur

1. Menampilkan data terkini menggunakan chart di dashboard.
2. Menampilkan dan melakukan pencarian dan filter di data master.
3. Routing ke setiap halaman.
4. Tema gelap dan terang di localStorage.

# Install

1. Install dependencies: `pnpm install`
2. run: `pnpm run dev`
